Data practices

Privacy policy

Effective date: October 28, 2026

This policy describes GymUp Sync, a personal desktop integration operated by its account owner, and this information website.

Google data accessed

With your authorization, the locally installed rclone client accesses Google Drive file metadata and downloads backups from the configured GymUp folder. Metadata includes file names, identifiers, sizes, modification times and checksums.

Backup contents can include workout dates, exercise names, repetitions, loads, notes and other records stored by GymUp.

The drive.readonly OAuth scope permits reading files throughout your Drive. Selecting a folder in the sync configuration limits the tool's operation, not the permission granted by Google. The integration does not upload, modify or delete Drive files.

Purpose and processing

The data is used to maintain local backup copies and a local workout history. The importer validates backups and produces workout and set records. It may use body-weight measurements already stored locally to estimate volume for bodyweight exercises.

The sync process does not use Google data for advertising, resale or profiling, and has no AI or model-training component.

Storage and sharing

Backups and derived records are stored on the account owner's computer. OAuth credentials and tokens are kept in the local rclone configuration, separate from the website and source repository. Requests to Google use HTTPS.

The sync process does not send downloaded workout data to a hosted application server, this website, analytics providers or advertising services. Access by other software that the owner chooses to use with local files is controlled by the owner and that software's settings.

Google API data is handled in accordance with the Google API Services User Data Policy and its Limited Use requirements.

Retention and your control

Local backups and imported records remain until the account owner deletes them. There is no automatic retention deadline for original backups.

You can stop the local scheduled job and revoke the application's authorization in Google Account connections. Revoking access does not remove copies already downloaded. To remove those copies, delete the local backup and processed-data files; credentials can be removed from the local rclone configuration.

This website

These static pages contain no analytics, advertising, submission forms or third-party scripts, and set no application cookies. When served through GitHub Pages, GitHub may process ordinary request metadata under its privacy statement. Workout backups and OAuth credentials are not sent to this website.

Contact and changes

For questions about the application or deletion of local data, contact the operator using the developer support email shown on the Google authorization screen.

Changes to these data practices will be reflected here with an updated effective date. Any additional Google permissions must be explicitly authorized.
